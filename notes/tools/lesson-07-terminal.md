Lesson 7: The Terminal - How Engineers Actually Talk to Computers

What a terminal is: A terminal allows you to write exact commands for the computer to perform and this is beter then a GUI since its more percice rather then having the computer doing specifics.

When you use Git Bash to open the terminal you get the name that represents you, the computers name next to your name, the architecture that your computer has which in this case is 64 bit windows, your current location represented by ~ and the $ which means the terminal is ready and waiting for you.
