Lesson 7: The Terminal - How Engineers Actually Talk to Computers

What a terminal is: A terminal allows you to write exact commands for the computer to perform and this is beter then a GUI since its more percice rather then having the computer doing specifics.

When you use Git Bash to open the terminal you get the name that represents you, the computers name next to your name, the architecture that your computer has which in this case is 64 bit windows, your current location represented by ~ and the $ which means the terminal is ready and waiting for you.

One of the first commands I have learned is pwd, which means: print working directory. It tells you where you are in the file system and is an essential first command whenever you use Git bash.

When I frirst typed pwd and press enter it showed me my location which was the C: drive, the users folder and my home folder.

The second command I learned is ls, which means list and it shows me every file in my current location.

The third command I learned is cd, which means change directory and it moves you into a new folder which is kind of like double clicking a folder.
