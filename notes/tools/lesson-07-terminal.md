Lesson 7: The Terminal - How Engineers Actually Talk to Computers

-Everything you've done on GitHub so far has been through a browser. That's fine for notes. But when you write Python code, run simulations, and eventually work with ROS 2, you'll be talking to the computer directly - through a terminal.

What a terminal is:

Browser/GUI: You click buttons. The computer guesses what you mean.
Terminal:    You type exact commands. The computer does exactly that.

No guessing. No menus. Direct control.

-This is why every serious enginner, robotics lab, and every job you're targeting runs on terminal commands.

Step 1- Open Your terminal Right now
You're on Windows. You have two options:

Option A - Git Bash:
Press Windows key, type Git Bash, open it.

Option B - Windows Terminal or Command Prompt:
Press Windows key, type cmd or terminal.
