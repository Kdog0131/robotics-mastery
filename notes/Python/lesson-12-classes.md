What is a class and what is an object: A class is a set of instructions in a compact block of code that allows us to make objects that use those instructions. An object is a variable created from what was initalized in the class ad uses those attributes.

What does __init__ do and when does it run: __init__ creates the classes attributes and it runs automatically when you create an object from a class.

What does self mean and why do we need it: Self is what specifies each attribute and we need it to refer to the specific object that called a classes method. So robot_1.check_obstacle() - self is robot_1, Robot_2,check_obstacle() - self is robot_2.

What did building two robots from one class teach you: What this has taught me was that multiple objects can use the classes attributes but it is wise to make each object distinct from eachother to avoid confusion.
