What is File I/O and why do robots need it: Robots need file I/O in order to save the data they are analysing and transmitting so that it can be reviewed later.

What is the difference between "w", "a", and "r" modes: w means overwrite which means a robot will continuously restart the information it is sending to the text file, a means append which means the robot will add a new reading to the text file without erasing wat was saved and r means read which will read what was already added to the text file.

What does "with open(...) as f" do: "with open(...) as f" opens the file safely and automatically closes it when the block is done. "f" is the name we use to write or read inside that block.
